02 · What it is

One command. Your machine joins a live market.

$ npm i -g pear
$ pear install pear://8f789f6h…znpny
$ pyrusllm serve --swarm

No repo to clone, no build step, no package registry. The distribution channel is the P2P network: the binary carries the inference engine inside it and updates itself over the air.

Point any OpenAI client at it

Your terminal, a Telegram bot, Open WebUI, an agent framework. Same base URL, same request shape, no code changes.

sell

Serve inference from idle hardware

The node runs a local LLM, announces a signed manifest with its models and capacity, and answers requests from verified peers.

both

Every node is both sides

The protocol is symmetric. There is no proprietary server in the middle, and no privileged path a node can take that a peer cannot.
