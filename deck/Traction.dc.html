04 · State of the product

What runs today — and what doesn't, said out loud.

Shipped and measured
24 sfrom pear install to the first token
~10 sfor an OTA update to reach a running node, with no user action
81 MBinstalled cross-machine, Windows → MacBook Air over a phone hotspot — the Mac picked its own architecture unaided
7/7soak runs clean, across 5 platform binaries
sigEd25519 manifests over canonical JCS (RFC 8785), with the signature bound to the connection key — a valid signature from the wrong peer is rejected
apithe real OpenAI protocol: models, streaming completions, error shape
Not built yet
meterno token accounting. The engine does not expose usage, so there is no unit of account — and without one, nothing downstream can exist
paythe manifest's economic block is a mock — a zero wallet, flagged _mock in the source rather than dressed up
repno reputation. We count per-peer activity; nothing scores it yet
routerequests don't pick a node by load yet — a market that always picks the first peer isn't a market
privthe serving node reads the prompt in plaintext. Closing that needs confidential inference hardware — we are not claiming it

Every gap on the right is written into the README and the source before anyone asks. A judge who opens the repo finds the same list — that is the point.
