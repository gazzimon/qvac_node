Preparation

What's under test is the real install: the binary an end user downloads, not node bin.mjs from the repo. The repo is only needed for scripts/ and the test suites.

  • Machine A — the one running the full pass. Windows 11 or macOS/Linux.
  • Machine B — second machine, on another network or on the same hotspot. It only needs to run pyrusllm serve --swarm.
  • Network — if P2P doesn't discover peers, suspect the network before the code: a corporate AP that blocks UDP breaks hole-punching. Plan B: phone hotspot on both machines.
  • Nothing listening on 8787 — an old gateway left open is the single most likely error in the whole pass.
  • Provider credentials — the Phase 8 and 8.5 tests (T30 to T36) require at least one NVIDIA or OpenRouter API key in .env. Without one, that entire block is BLOCKED, not FAIL.
  • Wallet passphrase — PYRUS_WALLET_PASSPHRASE in .env, long and unique. Without it the Phase 7 wallet can't be created or opened.

# The credential does NOT go in that file: the environment variable NAME goes

# secret never ends up in the signed manifest announced to the network.
