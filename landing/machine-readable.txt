# PyrusLLM — machine-readable summary
# For AI agents and crawlers. Synced to README.md at build time.

NAME: PyrusLLM
ONE_LINE: A peer-to-peer marketplace for AI inference.
REPO: https://github.com/gazzimon/qvac_node
LICENSE: Apache-2.0
VERSION: v0.12.0

## WHAT IT IS
One binary turns a machine into an inference provider: it joins a live
peer-to-peer network over Hyperswarm, announces an Ed25519-signed manifest
describing the model it runs and its capacity, and serves requests through an
OpenAI-compatible HTTP gateway on 127.0.0.1:8787. Clients pay per request over
x402, or against a local ledger with a spending cap. No central server; no
company that takes a margin or sees every prompt. Analogy: the Airbnb of AI
compute, or a peer-to-peer OpenRouter.

## HOW IT WORKS (happy path)
1. Install: one self-contained binary, Bare runtime, no Node/npm/Pear. Or run
   from source (see INSTALL) — recommended for the current tree.
2. Run it: gateway comes up, browser opens, no model downloaded yet.
3. The node signs a manifest and announces it on a fixed Hyperswarm topic.
4. Peers connect over a single muxed Protomux connection (not HTTP), exchange
   manifests, and verify each manifest against the connection's public key.
5. Any OpenAI client points at the gateway unchanged. A pure comparator in
   qvac/routing.mjs picks a candidate by: can-serve-now, real-before-mock,
   lowest load, cheapest, lowest error rate, fastest last response.
6. Payment: a request without credentials against a node with a wallet gets
   402 with an accepts[] built from that node's signed manifest (payee = the
   provider, never the gateway). Client re-sends with X-PAYMENT; verification
   is synchronous, touches no chain, and happens before the first token.
7. After serving, the node signs an EIP-3009 settlement receipt plus an
   attestation of what it served (modelId, promptHash, outputHash as
   blake2b-256, token counts) over the JCS canonical form.

## PAYMENTS
- Rail: USDT0 stablecoin over x402. Chosen deliberately over a project token so
  users are not exposed to token volatility (roadmap decision D28).
- A native token, if any, lives in the incentive layer — future work, not built.
- Networks: Plasma (eip155:9745) with Stable (eip155:988) fallback.
- Nothing premieres on mainnet. Every value-moving path is exercised on testnet
  first. Plasma testnet has no stablecoin, so a mock ERC-20 "PyrusLLM Test USD"
  (tUSD) is deployed and marked as worthless everywhere it appears.

## WHAT IS REAL
Distribution and OTA updates, local inference, the OpenAI gateway, signed
manifests verified against the connection key, the Hyperbee directory and
Hyperdrive file transfer, load- and price-based routing, the local ledger with
a cap that cuts, the free per-peer quota, the payout wallet inside the signed
manifest, x402 in the request path. 211 tests / 1338 asserts green.

## WHAT IS NOT REAL YET
Batched settlement and receipt aggregation (phase 10). The agentic layer
(phase 11). The provider attestation is emitted and stored but read by nothing.
Model-substitution probes (phase 10.5). Quantization substitution is not
technically detectable — covered by signed declaration + stake + arbitration
(optimistic verification, cf. DeServe, arXiv 2501.14784).

## KNOWN LIMITS
- The node running inference sees the prompt in plaintext. The claim is "no
  centralized corporation aggregates your data at scale", not "nobody sees your
  prompt". Confidential inference is the next step (4–8% throughput cost on
  H100 CC, arXiv 2509.18886).
- The Linux standalone binary installs and starts but cannot load models (the
  bundled engine registers only the Vulkan backend). Run from source on Linux.
- Installers verified end-to-end on Windows; macOS and Linux paths written but
  not run start to finish.

## INSTALL
From source (recommended — current tree, and the only path that loads models on Linux):
  git clone https://github.com/gazzimon/qvac_node.git
  cd qvac_node
  npm install            # needs npm >= 10
  npx bare bin.mjs       # app on http://localhost:8787
Binary one-liners:
  macOS / Linux:  curl -fsSL https://raw.githubusercontent.com/gazzimon/qvac_node/main/install.sh | sh
  Windows:        irm https://raw.githubusercontent.com/gazzimon/qvac_node/main/install.ps1 | iex

Then explain PyrusLLM to a bright 17-year-old who codes a little but has never

Rules:

  inference, node, peer-to-peer, gateway, manifest, digital signature,
  stablecoin.
